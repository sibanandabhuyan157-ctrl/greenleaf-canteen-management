# 🧡 CampusLeaf Canteen — Simple College Canteen Management System

![Orange Leaf Logo](./logo.svg)

A clean, beginner-friendly **Offline & Online College Canteen Management Website** built with minimal source code using **HTML, CSS, JavaScript, PHP, and MySQL** in an **Orange & White** theme.

- 🌐 **Live Public Website**: https://sibanandabhuyan157-ctrl.github.io/greenleaf-canteen-management/
- 📦 **GitHub Repository**: https://github.com/sibanandabhuyan157-ctrl/greenleaf-canteen-management

---

## 📁 Minimal 6-File Structure (Easy for College Project Viva)

| File | Purpose |
| :--- | :--- |
| `index.html` | Main single-page interface with 3 tabs (**Order Food**, **Employee Orders**, **Manage Menu**) |
| `style.css` | Simple **Orange & White** stylesheet |
| `script.js` | Short, clean JavaScript for Cart, Token Receipt, Order Status, and Menu CRUD |
| `backend.php` | Single PHP script connecting to MySQL (`mysqli`) |
| `database.sql` | 2-table MySQL database (`menu` and `orders`) |
| `logo.svg` | Custom **Orange & White Leaf Logo** |

---

## 🚀 How to Run on XAMPP (PHP + MySQL)
1. Copy the folder to `C:/xampp/htdocs/canteen/`.
2. Start **Apache** and **MySQL** in XAMPP, open `http://localhost/phpmyadmin`, and import `database.sql`.
3. Open `http://localhost/canteen/` in your browser.
